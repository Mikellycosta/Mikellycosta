### 💧 Sistema Automatizado de Controle de Nível de Reservatório

Projeto desenvolvido com **Arduino** para automatizar o controle do nível de um reservatório.

**Recursos utilizados:**

- 🔊 Sensor ultrassônico HC-SR04
- 💡 LEDs indicadores de nível
- 🔔 Buzzer para nível crítico
- ⚙️ Controle automático de bomba
- 📊 Monitoramento pelo Serial Monitor
- 🔌 Arduino Uno
- 🔧 Registrador 74HC595

**Lógica do sistema:**

| Nível | Indicador | Bomba |
|---|---|---|
| Abaixo de 15% | 🔴 LED + buzzer | Ligada |
| 15% – 30% | 🟡 LED | Ligada |
| 30% – 90% | 🟢 LED | Ligada |
| Acima de 90% | 🟢 LED | Desligada |
